GAMMA — Armor Randomizer Terminal (v0.5: броня + оружие)

ТРЕБУЕТ:
- Gadgets for Hideout Furniture - DoktorDauerfeuer

УСТАНОВКА:
1. Установить ZIP через Mod Organizer 2 как отдельный мод.
2. Поставить НИЖЕ "Gadgets for Hideout Furniture - DoktorDauerfeuer" в левой панели MO2, чтобы патч имел больший приоритет.
3. Запустить игру.

ПРЕДМЕТ:
armor_randomizer_terminal

Гаджет использует модель ноутбука и устанавливается как отдельный предмет мебели.

РЕЖИМЫ: «БРОНЯ», «ОРУЖИЕ», «ЧИСЛО».

РЕЖИМ «БРОНЯ»:
- Сканирует только ближайшие inventory_box/хранилища вокруг установленного терминала.
- Радиус: 1 / 3 / 5 / 10 / 15 м.
- При смене радиуса выполняется немедленный повторный скан.
- Категории: лёгкая, средняя, тяжёлая, экзоскелеты, шлемы.
- Нажатие категории открывает список всех найденных экземпляров в ней.
- В списке показывается название предмета и контейнер.
- Кнопка «СЛУЧАЙНАЯ БРОНЯ ИЗ ВСЕХ» в главном меню выбирает из ВСЕЙ найденной брони.
- Внутри категории кнопка меняется на «СЛУЧАЙНАЯ БРОНЯ В КАТЕГОРИИ» и выбирает только из выбранной категории.
- Никакие предметы не перемещаются и не изменяются.

РЕЖИМ «ОРУЖИЕ»:
- Работает так же, как «БРОНЯ»: тот же радиус, те же хранилища, список, предпросмотр иконки.
- Категории: пистолеты, пистолеты-пулемёты, дробовики, винтовки (штурмовые + пулемёты), снайперские винтовки.
- Классификация по kind секции предмета: w_pistol / w_smg / w_shotgun / w_rifle / w_sniper.
- Патроны, обвесы, ножи, гранаты и подствольники не учитываются.
- Кнопки случайного выбора: «СЛУЧАЙНОЕ ОРУЖИЕ ИЗ ВСЕХ» (главное меню вкладки) и «СЛУЧАЙНОЕ ОРУЖИЕ В КАТЕГОРИИ» (внутри категории).
- Последняя открытая вкладка запоминается до перезапуска игры.

РЕЖИМ «ЧИСЛО»:
- Поля «От» и «До».
- Границы можно вводить в любом порядке; мод сам поменяет их местами при необходимости.

КЛАССИФИКАЦИЯ БРОНИ:
- Экзоскелеты определяются в первую очередь по repair_type=outfit_exo.
- Шлемы — kind=o_helmet / helmet repair type.
- Остальное — kind=o_light/o_medium/o_heavy с fallback на repair_type.

ПРИМЕЧАНИЕ:
Это первая тестовая версия отдельного UI. Если конкретная сборка GAMMA переопределяет XML/UI API или типы контейнеров, приложите xray_*.log после открытия терминала — патч можно адаптировать точечно.
